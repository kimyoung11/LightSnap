# LightSnap browser playground

설치 없이 모의 창으로 배치·순환·모니터 이동·복원을 체험하는 정적 페이지입니다. 네이티브 앱과 별개이며 실제 창 제어, 접근성 권한 검사, 로그인 자동 실행, 네이티브 성능 측정은 수행하지 않습니다.

## 로컬 실행

저장소 루트에서:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory preview
```

브라우저에서 `http://127.0.0.1:4173`에 접속합니다. ES module을 사용하므로 파일을 직접 더블클릭하기보다 HTTP 서버로 실행해 주세요.

```sh
node --test preview/model.test.mjs
node --check preview/app.mjs
```

## 구조

- `index.html`, `style.css`: 반응형 소개 페이지와 키보드/스크린리더 컨트롤.
- `model.mjs`: 브라우저용 정규화 좌표 시뮬레이션. Swift 코드를 직접 실행하지 않습니다.
- `app.mjs`: DOM 렌더링과 입력 처리. 상태는 메모리에만 유지합니다.
- `model.test.mjs`: 순환·창별 최초 복원·모니터 이동·화면 분리 등 12개 회귀 테스트.
- `assets/`: 저장소 자체 SVG 일러스트와 미리보기 이미지. 실제 앱 스크린샷처럼 표시하지 않습니다.

서버·분석 SDK·외부 API·원격 폰트·쿠키·브라우저 저장소를 추가하지 않았습니다. 페이지와 정적 파일을 받는 HTTP 요청은 호스팅 서비스가 처리합니다. GitHub 링크는 사용자가 직접 클릭한 경우 이동합니다.

## 게시

미리보기는 별도의 Sites 프로젝트에 정적 파일로 게시합니다. Swift 저장소의 공개 여부와 Sites 방문 권한은 서로 다른 설정입니다. 현재 사용자의 요청에 따라 둘 다 비공개로 유지합니다. 공유하려면 각 서비스에서 원하는 범위를 직접 변경하세요.

Sites의 별도 배포 체크아웃에는 이 디렉터리의 정적 실행 파일을 `dist/`로 복사합니다. `model.test.mjs`와 README는 게시 산출물에서 제외합니다. 호스팅 ID는 비밀키가 아니며 배포 인증 토큰은 소스·문서·커밋에 넣지 않습니다.

Swift의 레이아웃·복원·순환 동작을 바꿀 때는 브라우저 모델도 명시적으로 검토하고 갱신합니다. 브라우저 검사는 OS의 AX·Carbon·TCC 검사를 대신하지 않습니다. 드래그 스냅과 커스텀 레이아웃은 이 데모에서도 구현되지 않았습니다.
